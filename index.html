SUPER_3CAN 網頁開關

在 BLE Link 裡打開這頁，連上盒子就能按開關。命令和小程序版相同，送出的是文字命令加 \r\n。

這個瀏覽器沒有 Web Bluetooth iPhone 請用 BLE Link App 打開這頁；Android／電腦請用 Chrome。Safari 本身連不了藍牙。
目前不是 HTTPS 連線 Web Bluetooth 只在 HTTPS 頁面運作，請確認網址是 https 開頭。
